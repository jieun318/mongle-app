---
name: Execute-don't-ask when intent is clear
description: User prefers I apply changes directly rather than asking which option to pick when intent is reasonably clear from prior context
type: feedback
---

When the user has expressed a clear preference and asks me to make a change, apply it directly instead of presenting options and waiting for selection.

**How to apply:** When the next step is clear (e.g., "use option A", "make it lighter", "try a different color"), execute it. Reserve clarifying questions for genuine forks where defaults could waste real work (architecture, irreversible actions, brand-level design like splash screen content). For visual polish on existing components, just apply and iterate.
